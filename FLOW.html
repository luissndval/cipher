Comandos

🚀
cipher init
Registra repos y genera contexto inicial
  • 1Escanear directorio → repos .git
  • 2Elegir proveedor: Gemini (400k) o Claude (60k)
  • 3Nombrar cliente
  • 4Analizar con LLM → ARCHITECTURE · RULES · DEPS LLM
  • 5Indexación estructural sin LLM DET
  • 6→ index.json + graph.json
🔍
cipher index
Indexa código sin LLM · extrae estructura real
  • 1Python → ast.parse() clases, funcs, imports DET
  • 2TypeScript/JS → regex: interfaces, clases, require
  • 3Go → FSM: structs, interfaces, funcs, import blocks
  • 4→ .cipher/index/<repo>/index.json
  • 5→ .cipher/index/<repo>/graph.json
⚡
cipher impact <archivo>
¿Qué se rompe si cambio este archivo?
  • 1Carga graph.json del repo DET
  • 2BFS sobre grafo invertido (dependents)
  • 3Retorna ImpactEntry[] con depth + via-chain
  • 4Agrupa resultado por nivel de profundidad
  • 5Flags: --depth <n> · --repo <nombre>
📦
cipher pack <descripción>
Contexto mínimo para una tarea · sin LLM
  • 1Scorer léxico: path +2 · símbolo +1 · inbound +0.5 DET
  • 2Selecciona top archivos como target
  • 3Expande dependencies via grafo
  • 4Budget: 60k Claude · 400k Gemini · trim por newline
  • 5→ context_pack.md + context_manifest.json
🎯
cipher task <descripción>
Task formalizada → intent → pack → agente
  • 1Fetch ticket: Manual · GitHub · Linear DET
  • 2Crea task.json · detecta tipo HOTFIX/BUG/FEATURE/TASK
  • 3PackBuilder → context_pack.md
  • 4AuditWriter → CONTEXT_MANIFEST.json + audit_log.jsonl
  • 5TaskAnalyzer → task_intent.json (files · constraints)
  • 6Lanza agente con pack + intent LLM
🔎
cipher audit
Trazabilidad completa · ¿qué vio la IA?
  • 1Lee audit_log.jsonl (append-only) DET
  • 2Filtra: --repo · --client · --since · --result
  • 3cipher audit <task_id> → detalle + PR comment preview
  • 4--stats → tokens totales · por repo · por resultado
  • 5--pr <task_id> <url> → registra PR en manifest + log

Scoring léxico (sin LLM)

Usado por cipher pack y cipher task para encontrar archivos relevantes.

+2.0
Palabra de la tarea en el path del archivo
+1.0
Palabra en nombre de símbolo (clase/función)
+0.5
Archivo muy importado (top 20%, mín. 3 inbound)
+0.3
Archivo tiene símbolos definidos (no solo imports)

Estructura de archivos

.cipher/
  config.json ← clientes + repos registrados
  config.local.json ← API keys (gitignored)
 
  index/<repo>/ ← generado por cipher index
    index.json ✓ DETERMINÍSTICO — símbolos + imports
    graph.json ✓ DETERMINÍSTICO — nodos + aristas
 
  packs/<repo>/<task_id>_<slug>/
    context_pack.md ← contexto recortado por budget
    context_manifest.json ← hash + tokens + files
 
  tasks/<client>/<repo>/<task_id>/
    task.json ← PENDING → IN_PROGRESS → DONE | FAILED
    task_intent.json ← files_to_modify · constraints
 
  sessions/<client>/<repo>/<task_id>/
    CONTEXT_MANIFEST.json ← qué vio la IA (F5 — trazabilidad)
 
  audit/ ← historial append-only
    audit_log.jsonl ← una línea JSON por sesión
 
  clients/<client>/<repo>/ ← generado por cipher init con LLM
    ARCHITECTURE.md ⚠️ DRAFT — no es verdad estructural
    BUSINESS_RULES.md ⚠️ DRAFT
    DEPENDENCIES.md ⚠️ DRAFT
    RISK_MATRIX.md ⚠️ DRAFT
